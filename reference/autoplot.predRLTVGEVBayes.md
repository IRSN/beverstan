# Autoplot a `PredRLTVGEVBayes` object

Autoplot the predictive distribution computed from a `TVGEVBayes`
object, i.e. the result returned by the `predict` method for such an
object.

## Usage

``` r
# S3 method for class 'predRLTVGEVBayes'
autoplot(object, ...)
```

## Arguments

- object:

  A `predRLTVGEVBayes` object.

- ...:

  Not used yet.

## Value

A graphical object inheriting from `"ggplot"`.
